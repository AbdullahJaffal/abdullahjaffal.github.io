GUIDE/CommandRibbon · DüzenlemerBProperties

Properties panel

TestedLive-tested in Civil 3D.
Where to find itRibbon: Düzenleme → Özellikler
Command linerBProperties
Works inCivil 3D · BricsCAD V26 · AutoCAD 2026

A side panel that shows the name and type of what you select — and, for manholes, their levels and cover height — and edits them for one element or for many at once. It stays open and updates whenever you select something.

Where to find it: Ribbon → UrBIM 3D → Düzenleme → Özellikler (the large button) · or type rBProperties

Steps

Section titled “Steps”
  1. Run the command. → “Özellik paleti açıldı. Çizimde bir öğe seçin.”.
  2. Select a pipe, a manhole or a group in the drawing. → The panel shows what applies to the whole selection.
  3. Edit the fields and press Uygula. → “{0} öğe güncellendi. Tek bir UNDO adımıdır.”.

Fields

Section titled “Fields”
Field Appears when Notes
Ad One element A name is a unique label, so it cannot be edited for several elements at once
Katalog tipi Everything selected is of one kind (pipes or manholes) A type the drawing has not used yet is copied into it from the catalog. If the selected elements have different types, the list shows empty
Hendek tipi / Baca kazı tipi Pipes only / manholes only (they disappear if a fitting or a valve is mixed in) The type that the excavation and backfill calculation will read. What you choose becomes yours (✎): Uygula in rBEarthworks does not touch it. And a type the drawing has not used yet is copied into it from the earthworks catalog. For many elements, or to return to the rule: rBTrenchType · rBPitType
Notlar Always A free note
Seviyeler Manholes only A box for each level defined in rBLevels
Kapak yüksekliği (m) Manholes only Above (+) or below (−) the “depth reference” level
Boru altındaki baca derinliği [m] Manholes only How far the manhole’s bottom goes below the pipe; the list below it chooses where it is measured from (Borunun dış kenarının altından / Borunun akar kotunun altından). For many manholes: rBNodeType
Başlangıç akar kotu (m) / Bitiş akar kotu (m) Pipes only (the Akar kotları section) The internal invert level at the pipe’s start and end (in the drawing direction). To set them along a whole route: rBInvert
Slope and depth One pipe Read only: the slope is derived from the two invert levels and the length, in the format chosen in rBSettings, and is negative if the pipe rises in its drawing direction; the depth runs from the “depth reference” at each manhole down to the internal invert
Pipe length Pipes “Seçilen boruların toplam uzunluğu: {0} m” — read from the drawing
Parametreler If a parameter is defined at the Öğe level for every selected kind The values of your own fields in each element — see below
Hidrolik girdiler Pipes alone or manholes alone The numbers the hydraulic calculation will take from this element — see below

An empty box among the levels and invert levels means the selected elements have different values there (or none), and leaving it empty erases nothing — each manhole keeps its own value. Numbers accept a comma or a point.

Parametreler

Section titled “Parametreler”

The parameters you defined in rBCatalogs → the Parametreler tab at the Öğe level — year of construction, leak test… The ones defined for every selected kind (pipe, manhole, storm inlet…) appear, each with a box: numbers and text are typed (numbers in your machine’s format, such as 2,5), and yes / no and lists are chosen.

  • The box shows the value shared by the selected elements; if they differ it is empty — and leaving it empty erases nothing.
  • To clear a shared value, empty the box.
  • Uygula writes the value into every selected element; if the parameter is not in the drawing it is copied into it from the library. A value that does not suit its type (letters instead of a number…) is not written, and the status line says why.
  • The values are data: nothing is calculated with them.

Hidrolik girdiler

Section titled “Hidrolik girdiler”

The numbers the hydraulic calculation will take from this element — the columns of the two İSKİ calculation tables (Atıksu table 9, Yağmursuyu table 13) that the engineer writes. The hydraulic calculation itself is not in the program yet; these numbers are written from now and saved in the drawing.

Selection The boxes
Pipes of a Atıksu network İskan alanı (ha), Sanayi alanı (ha), Nüfus yoğunluğu (kişi/ha), Nüfus, Kullanma suyu (l/kişi/gün), Sanayi birim debisi (l/s/ha)
Pipes of a Yağmursuyu network Kısmi alan (ha), Akış katsayısı C (0–1), Giriş süresi (dak)
Pipes of a Birleşik sistem network or a network with no type Both groups
Manholes Ek debi (l/s) and Ek debi açıklaması
  • The load written in a pipe is its own load, and it enters at its start; what comes from above it will be added up in the calculation.
  • An empty box is “not given”, not zero. If the consumption, the industrial discharge per hectare or the inlet time is empty, the network’s value is taken, then the standard’s.
  • If Nüfus and Nüfus yoğunluğu are both written, the population you wrote is the one used.
  • Ek debi is a design (peak) discharge — a special building, a single industrial facility, a pump outlet — added as it is and not multiplied by the peak factor again.
  • The box shows the shared value; if the values differ it is empty, and leaving it empty keeps each one’s value. To clear a shared value, empty the box. A value that cannot be (a negative area, a C greater than 1, zero minutes) is not written, and the status line says so.
  • If the pipe is split by a manhole placed on it (rBNode) or by a new vertex, the load stays in one of the two pieces (the one that keeps the pipe’s identity), and the other is born with no load — distribute it if needed. If two pipes are merged, the load of the longer one stays.

The catchment «Havza alanı»

Section titled “The catchment «Havza alanı»”

When catchments alone are selected, the panel shows the catchment’s own fields:

Field What it is
Ad When a single catchment is selected; it changes the given name, such as «HV1»
Kullanım İskan or Sanayi: the column its area enters in the sewer calculation. It appears only in networks that carry sewage
Hidrolik girdiler The pipe’s inputs except the areas and Ek debi — the catchment’s area comes from the drawing: for sewer Nüfus yoğunluğu, Nüfus, Kullanma suyu and Sanayi birim debisi; for storm water Akış katsayısı C and Giriş süresi

Uygula writes into every selected catchment, as a single undo step; an empty box is “not given” or “different”, as with the pipe. Beneath them, in grey boxes: for one catchment Alan (ha, or the reason it is absent) and Boşaldığı öğe (a pipe or manhole, or Bağlantısız); for several catchments Toplam alan and the number with no area and the number unlinked. The link is changed by rBCatchment.

If catchments are selected together with pipes or manholes, they are left out: «{0} havza da seçili; havzaları düzenlemek için yalnız onları seçin.».

Mixed selection

Section titled “Mixed selection”

Pipes and manholes together: “{0} baca ve {1} boru seçildi. Yalnızca ikisinde de bulunan alanlar değiştirilebilir.” — there is no type list, because a pipe type and a manhole type are not the same thing. Choose “Borular” or “Bacalar” in Seçimi daralt so that the edit applies to that kind alone; a grey line reminds you how many elements of each kind are actually selected in the drawing. Going back to “Hepsi” does not lose the selection.

A selection that spans two networks: “Seçim birden fazla sisteme yayılıyor. Sistemlerin varsayılan tipleri ve katalogları farklı olduğundan toplu değişiklik yapılamaz.”

What you typed by hand

Section titled “What you typed by hand”

A value you type here becomes yours: automatic commands such as rBName do not write over it. A “Bu alanları siz yazdınız: {0}. Otomatik işlemler (rBName gibi) onlara dokunmaz.” bar appears with a Otomatiğe bırak button that lifts the protection (the value stays — and for the trench or pit type, the next Uygula writes the rule’s type). The bar only appears if all the selected elements are protected.

What changes in the drawing

Section titled “What changes in the drawing”

What you changed, only on Uygula, as a single undo step. Changing a manhole’s type also changes its symbol in the drawing to the new type’s symbol, and it takes its category (manhole, grate, fitting…) from the type. To give a type to many elements from a list: rBPipeType · rBNodeType.

Bilgiler

Section titled “Bilgiler”

When a single pipe or a single manhole is selected, below Uygula there appear values that are not its own but describe it, in grey boxes that are not edited here (and can be copied); each is edited where it belongs.

Selected What is shown
Pipe Şebeke, Başlangıç bacası / Bitiş bacası, Yatay uzunluk (m), Eğik uzunluk (m); the value of the two manholes for each level in rBLevels (such as KIRMIZI KOT — başlangıç and — bitiş — to change them, select the manhole); and from its type Malzeme, Dış çap (mm), İç çap (mm), Et kalınlığı (mm) and Sınıf
Manhole Şebeke, Kategori, and from its type the material, the construction method and the internal dimensions; Kapak kotu (m) (depth reference + cover height), En düşük akar kotu (m), Derinlik (m) (the reference − the lowest invert); the excavation and backfill levels — and in brackets which level they are in that network (rBLevels); the source of each level (manual, from a surface…); Baca parçaları if the quantities have calculated it — see below; Ekler and Kaplamalar — see below; Bağlı boru sayısı; the outgoing pipe first, then the incoming ones — each with its type, its two diameters and its invert level at this manhole; and X and Y

For a single pipe or a single manhole there is also Bağlı havzalar: the catchments that flow into it, each with its area (and, for one with no area, the reason), and their total if there is more than one. If there is nothing: «(yok)».

A manhole outlet’s diameter is not stored on its own: it is the diameter of the outgoing pipe itself, which is why it is read from here.

Baca parçaları

Section titled “Baca parçaları”

When rBMetraj calculates a manhole, its pieces are saved in the manhole itself, and they appear here when a single manhole is selected:

  • In the heading is their source: Motor (rBMetraj) — proposed by the quantities engine — or Elle düzenlendi — set by you with rBManholeStack; and if it is cast in place, or the assembly catalog gave it no pieces, that is written too (Yerinde döküm, Montaj kataloğunda eşleşme yok);
  • Each piece from bottom to top with its height — and if the same piece repeats, 2 × …, and a piece whose height is set on site (değişken);
  • Toplam yükseklik: the sum of the pieces, and beside it the manhole depth they were stacked for.

The next rBMetraj proposes the engine’s pieces again; it does not touch the pieces you set, and calculates the quantities with them. You edit the pieces with rBManholeStack.

Ekler

Section titled “Ekler”

The accessories the manhole carries — what its type names in rBCatalogs, with what the manhole changed and what it added: each with its quantity and unit. Beside what differs from the type is the type’s quantity («10 Adet (tipte 8)»); what the manhole removed is «kaldırıldı (tipte 2)», and what it added «(eklendi)». This heading does not appear for a manhole with no accessories. You change the accessories with rBAccessories.

Kaplamalar

Section titled “Kaplamalar”

The coatings the manhole carries — what its type names in rBCatalogs, with what the manhole changed and what it added: each with its material name, and beside it the face and the thickness, or the number of coats and the extent («Dış yüzey, 2 kat, tüm yükseklik»). At the end of what differs from the type is «(tipte farklı)», what the manhole removed is «kaldırıldı», and what it added «(eklendi)». This heading does not appear for a manhole with no coatings. You change the coatings with rBCoatings.

Tip parametreleri

Section titled “Tip parametreleri”

For a single pipe or a single manhole, the values of its type’s parameters at the Tip level — manufacturer, class… are the type’s values: they are not written here but in rBCatalogs under the type. A parameter with no value is not shown.

See also

Section titled “See also”

rBName · rBPipeType · rBNodeType · Catalog
