GUIDE/CommandRibbon · KotlarrBGround

Ground levels at manholes

PreviewBuilt; its live test in Civil 3D is not complete yet.
Where to find itRibbon: Kotlar → Arazi Kotu Ayarla
Command linerBGround
Works inCivil 3D · BricsCAD V26 Pro (needs a surface)

Writes a level value (finished grade, natural ground…) into the selected manholes: one by one, or one value for all, or an offset from another level, or linear interpolation between two values along a path, or from a Civil 3D surface.

Where to find it: Ribbon → UrBIM 3D → Kotlar → Arazi Kotu Ayarla · or type rBGround

Works in: AutoCAD 2026, Civil 3D 2026 and BricsCAD V26. The «Yüzeyden (Civil 3D)» method appears only in Civil 3D or BricsCAD, and only in a drawing that contains a surface (in BricsCAD it reads BricsCAD’s own TIN surfaces, and the name stays «Civil 3D»).

Steps

Section titled “Steps”
  1. Run the command. → A window with the manhole selection, Seviye and Giriş tipi.
  2. Select the manholes with the common selection (rBSelect): a method from the ▾ arrow (selection starts at once), or the Seç icon for the current method. → They appear in the Bacalar table in natural order, with their current value in the Mevcut column.
  3. Choose the level you write into, and the entry method (below).
  4. Uygula. → «‘{0}’: {1} bacaya yazıldı ({2} mevcut değer değiştirildi), {3} baca atlandı.».

Entry methods

Section titled “Entry methods”
Method What it does
Tek You type each manhole’s value in Yeni değer and press Enter to move down to the next. A manhole you leave empty does not change
Toplu değer One value for all the selected manholes
Ofset For each manhole: its value in Temel seviye + the offset (negative means down). A manhole with no base value is skipped by name — no value is invented for it
Yüzeyden (Civil 3D) The value is read from Yüzey at the manhole’s position, with an optional offset
Lineer enterpolasyon A value for the first manhole on a path and a value for the last; those in between by the distance along the pipes. It needs a path (below)

Linear interpolation — details

Section titled “Linear interpolation — details”
  • Select the manholes with a method that gives a path: «Bacadan bacaya», «Kol» or «Hat». With any other: «Lineer enterpolasyon bir yol ister: bacaları «Bacadan bacaya», «Kol» veya «Hat» ile seçin.».
  • The table is in path order, and İlk baca and Son baca are filled with the two ends’ current values — so filling in between is often a single press of Uygula.
  • As you type the two values, the Yeni değer column shows at once what each manhole will get (read-only in this method).
  • The distance is horizontal, along the pipes as they are drawn (a curved pipe by its arc length), not the straight line between the two ends.
  • The two ends are recorded with the source «Elle», and those in between with the source «Enterpolasyon». When reading from a surface, Elle girilmiş değerleri koru keeps them too.
  • The path’s pipes’ break points for this level are cleared: the ground between the manholes is now a straight line.

From a Civil 3D surface — details

Section titled “From a Civil 3D surface — details”
  • The value is fixed when it is read: if the surface changes or is deleted afterwards, the value does not change until you run the command again.
  • For a manhole outside the surface, no value is invented; you are asked about it by name before anything is written.
  • Elle girilmiş değerleri koru (on by default): the values you typed by hand stay. Turn it off to replace them.
  • Borular boyunca yüzeyi izle (kırık noktalar); kapalıysa iki baca arası düz çizgi: reads the ground along each pipe between two selected manholes, at every triangle edge it crosses — break points for the long section. → «Seçili bacalar arasındaki {0} borunun zemin çizgisi güncellendi ({1} kırık nokta); {2} boru atlandı.». A pipe with one end outside the selection is not touched, and a curved pipe is reported and no points are invented for it.

Questions before writing

Section titled “Questions before writing”

It asks only when there is something to ask about:

  • «{0} bacada ‘{1}’ için zaten bir değer var ve değiştirilecek. Devam edilsin mi?» — in «Toplu değer», «Ofset» and «Lineer enterpolasyon» (in «Tek» you see the old value as you type).
  • Manholes that will be skipped, by name.

What changes in the drawing

Section titled “What changes in the drawing”

The values written, each with its source (manual, an offset from a level, interpolation, or from a named surface). What does not change is not written and not counted. All of it is a single undo step.

Notes and limits

Section titled “Notes and limits”
  • Numbers with a comma or a point: 102,35 and 102.35 are both accepted. A mix such as 1.234,5 is refused and not guessed: «‘{0}’ bir sayı değil. Ondalık için nokta veya virgül kullanın.».
